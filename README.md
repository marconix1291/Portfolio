# Portfolio

**Marco Rodriguez - Software Developer**

Welcome to the repository for my personal portfolio website! I am currently studying Software Development (graduating in April 2027), and this site serves as my digital sandbox and resume. 

## Goals
The primary goals of this project are to:
- **Showcase My Work:** Provide a clean, highly visual space to display my software engineering projects, creative coding experiments, and UI/UX designs.
- **Demonstrate Frontend Skills:** Build a premium, performant website from scratch without relying on heavy frameworks, demonstrating my core web development abilities.
- **Experiment with Design:** Implement modern web design trends like glassmorphism, custom micro-interactions (like a custom cursor), and smooth scrolling animations.

## Tech Stack & Use
This portfolio is built using a lightweight, zero-build vanilla stack for maximum performance and simplicity:
- **HTML5:** Semantic and accessible structure.
- **CSS3:** Fully custom styling utilizing CSS Variables, Flexbox, Grid, and keyframe animations. It features a custom light pastel color palette.
- **JavaScript:** Handles interactive elements like the custom cursor, smooth scrolling, and scroll-triggered `IntersectionObserver` animations.

## Local Development
To run this project locally, simply clone the repository and open `index.html` in your web browser. No `npm install` or build steps are required.
